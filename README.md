# Literature Screener: downloads

**Download page: https://yifan-hu1.github.io/literature-screener-app/**

Literature Screener is a desktop app (Mac and Windows) for searching PubMed and screening
biomedical literature in projects stored on your own computer. It is currently in alpha testing
with invited testers.

This repository only hosts the download page and the installers (see *Releases*).
The source code is kept in a separate repository.
